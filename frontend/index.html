Read this before quoting the number

The public dataset is synthetic and encodes maintenance need as a deterministic function of service age and telemetry, so holdout discrimination is near-perfect. The pipeline excludes days-since-service, severity, cost and every post-service field. Re-validate on real fleet data before operational use.

Model 02 · regression

Freight quote

Submit a lane and shipment weight. The result includes a point estimate, a 90% interval, cost per mile and the observed lane benchmark.

How to read the interval

The 90% interval comes from absolute residuals on the validation split. It widens for unusual lanes and heavy shipments. A quote is a planning aid, not a booked rate.
